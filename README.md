# Agentic AI Lab Assignments

This repository contains the completed solutions for all 14 Agentic AI Systems lab sessions.

## Structure

- `Lab_01_Agent_vs_Chatbot/`
- `Lab_02_Tool_Using_Agent/`
- `Lab_03_Skill_Creation/`
- `Lab_04_Memory_and_Retrieval/`
- `Lab_05_MCP_Style_Connector/`
- `Lab_06_OpenCLA_Runtime/`
- `Lab_07_Agentic_Node_Graph/`
- `Lab_08_Parallel_Swarm/`
- `Lab_09_Deep_Research_Agent/`
- `Lab_10_Cloud_Operations_Agent/`
- `Lab_11_Agentic_SDLC_Factory/`
- `Lab_12_Safety_Evaluation_Governance/`
- `Lab_13_Discipline_Specific_Agent/`
- `Lab_14_Course_Project/`
- `Course_Project_Report.pdf`

Each lab folder contains:

- `reference.py`: runnable reference implementation
- `assignment1.py`: first graded assignment
- `assignment2.py`: second graded assignment

Run a solution from the repository root, for example:

```powershell
python .\Lab_01_Agent_vs_Chatbot\assignment1.py
```

Use the workspace virtual environment to execute all submissions and write execution evidence:

```powershell
.venv\Scripts\python.exe .\run_lab_tests.py
```

The status after execution is recorded in `PROGRESS.md`. Each lab folder contains `TEST_OUTPUT.txt` with commands, exit codes, standard output, and errors.
